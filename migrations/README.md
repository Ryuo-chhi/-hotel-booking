# Migrations Folder

## Responsibility
Contains Sequelize migration scripts for database schema alterations.

## Files
- `[timestamp]-create-users.js`: Creates the `users` table.
- `[timestamp]-create-room-types.js`: Creates the `room_types` table.
- `[timestamp]-create-rooms.js`: Creates the `rooms` table.
- `[timestamp]-create-bookings.js`: Creates the `bookings` table.
- `[timestamp]-create-transactions.js`: Creates the `transactions` table.
