# Seeders Folder

## Responsibility
Contains database data seeds for populating initial records (default room types, admin accounts, mock physical rooms) into the database.

## Files
- `[timestamp]-demo-room-types.js`: Populates base room types.
- `[timestamp]-demo-rooms.js`: Populates individual physical rooms.
- `[timestamp]-demo-users.js`: Populates default manager/admin and test customer accounts.
